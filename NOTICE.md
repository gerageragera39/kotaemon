# Notice and attribution

KURAGa — KU Retrieval-Augmented Guide Assistant — is based on the open-source [Cinnamon/kotaemon](https://github.com/Cinnamon/kotaemon) project, which is licensed under Apache-2.0.

This repository retains original Kotaemon architecture and components where applicable, including the internal `kotaemon` and `ktem` Python packages. It also contains substantial modifications by the KU Digital Projects team to support a university-document RAG chatbot with guest access, admin-managed document collections, local model defaults, evaluation utilities, and project-specific UI/documentation.

KURAGa is a university course project and is not an official KU service. The original license is retained in `LICENSE.txt`.
